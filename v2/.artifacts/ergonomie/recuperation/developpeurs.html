API LCD v1

Une API de lecture pour connecter votre reporting, votre outil d'automatisation ou votre guide voyageur. Toutes les réponses sont en JSON et restent limitées au compte qui a créé la clé.

Spécification OpenAPI 3.1 · Gérer mes clés

Authentification

Créez une clé depuis l'espace hôte. Elle est affichée une seule fois et commence par lcd_. Envoyez-la dans l'en-tête Authorization ; seules les empreintes SHA-256 sont stockées.

curl -H "Authorization: Bearer lcd_votre_cle" \\
  https://votre-domaine.fr/api/v1/logements

Scopes

Une clé ne peut lire que les ressources couvertes par ses scopes. Un scope manquant renvoie 403.

ScopeRessource
logements:lireLogements
reservations:lireRéservations
disponibilites:lireDisponibilités
prix:lireTarifs par nuit
proprietaires:lirePropriétaires
releves:lireRelevés propriétaires

Pagination

page commence à 1 ; limite vaut 50 par défaut et est plafonnée à 200. Chaque liste renvoie ses métadonnées :

{
  "data": [ … ],
  "pagination": { "page": 1, "limite": 50, "total": 120, "pages": 3 }
}

Erreurs et limites

Toute erreur a la forme { "erreur": { "code", "message" }, "requestId" }. X-Request-Id est repris s'il est fourni, sinon généré. Une clé est limitée à 120 requêtes par minute ; au-delà, la réponse 429 porte Retry-After.

  • 400 paramètre invalide (date, identifiant, fenêtre).
  • 401 clé absente, inconnue, expirée ou révoquée.
  • 403 scope manquant.
  • 404 logement introuvable dans votre compte.
  • 429 trop de requêtes.

Serveur MCP lecture

Un serveur MCP local expose les six lectures aux assistants compatibles (Claude Desktop, IDE, agents). Il parle JSON-RPC sur l'entrée/sortie standard et réutilise la même clé et les mêmes scopes que l'API ; aucun outil d'écriture n'est exposé.

LCD_API_URL=https://votre-domaine.fr \\
LCD_API_KEY=lcd_votre_cle \\
npm run mcp:lecture

Outils : lister_logements, lister_reservations, lister_disponibilites, lister_prix, lister_proprietaires, lister_releves. Les filtres et la pagination sont ceux de l'API.

Webhooks signés

Les webhooks sortants sont signés en HMAC-SHA256 : X-LCD-Signature: sha256=…. Vérifiez la signature sur le corps brut avant de lire le JSON, puis répondez 2xx. En cas d'échec, cinq tentatives sont espacées de 1, 5, 15 puis 60 minutes. Configurez-les depuis Intégrations.
