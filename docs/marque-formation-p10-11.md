# P10-11 — Dépôt marque INPI + formation continue

> Norme : socle v1 §S8 (formation 1/an min ; 2e personne formée avant le 3e client ;
> 1er salarié = DUERP + visite médicale + affichage). Produit : marque blanche
> par plugin (`{{marque}}`, `branding.yaml` — jamais en dur, batterie 0 fuite).
> Registre décision : `docs/registres/a-trancher.md` si arbitrage nom/budget.

## 1. Dépôt marque INPI (~200 €, avant le 3e client)

- [ ] Choisir nom + logo (vérifier distinctif, pas descriptif du service).
- [ ] Recherche d'antériorités INPI (identique + similaire, classes visées :
      35 gestion/commercial, 36 immobilier/garantie, 43 hébergement temporaire).
- [ ] Déposer en ligne (inpi.fr, ~200 € pour 1 classe de plus si besoin).
- [ ] Surveiller : opposition 2 mois, renouvellement 10 ans, journal à
      `docs/registres/` (date dépôt, n°, classes, statut).
- [ ] Ne pas attendre le dépôt pour exploiter : usage + preuves d'usage
      (factures, site, dashboards) dès le 1er client.
- Lien P10-8 : carte G + RC pro d'abord (bloquant mandat tiers) ; marque
  en parallèle, pas en préalable.

## 2. Formation continue (1/an min : ménage, accueil, pricing, sécurité)

| Thème | Contenu | Quand |
|---|---|---|
| Ménage | Checklists, photos AVANT/APRÈS, produits, écarts >20 % | avant go-live log1, puis 1/an |
| Accueil | Messages types 5 langues, SLA <15 min 8h-22h, gestes P1/P2 | avant go-live, puis 1/an |
| Pricing | `clamp(pivot × K_*)`, bornes, 1-tap, tradeoff mode, jamais d'auto-OTA | avant saison, puis 1/an |
| Sécurité | PIN jamais en clair, 1-tap tracée, WG, fuite token (runbooks) | avant go-live, puis 1/an |

## 3. 2e personne (avant le 3e client actif — §S8)

- [ ] Runbook 2 pages (quotidien : inbox, dispatch, prix, clôture).
- [ ] Drill : 1 journée doublon + 1 journée solo supervisée.
- [ ] Doc « indisponible 48 h » (qui fait quoi : astreinte, ménage,
      reversement reporté, message type).
- Sans 2e personne = pas de FULL au-delà de 2 biens.

## 4. 1er salarié (le jour venu — §S8)

- [ ] DUERP (document unique, dès l'embauche, revu 1x/an + à chaque accident).
- [ ] Visite médicale + affichage obligatoire.
- [ ] Coffre successoral (accès vault + runbook reprise + contacts
      expert-comptable/assureur, scellé, testé 1x/an).
