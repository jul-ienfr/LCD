# ADR-004 — i18n 5 langues, traductions UI humaines relues

Date : 2026-10-13. Statut : accepté (§17).

Contexte : dashboard + PWA + notifications + PDF multilingues dès v1.
Décision : catalogues `i18n/{fr,en,es,it,de}.yaml`, `t(cle, lang, vars)`,
priorité `?lang=` > profil > `Accept-Language` > entité > `fr`, clé
manquante = `[cle]` visible, `Content-Language` + `Vary`.
Chaînes UI socle (422/403) = humain relu UNIQUEMENT ; IA (faq/messagerie) =
brouillon + validation humaine, jamais d'envoi auto.
