# P10-12 — AG SAS annuelle + clôture des comptes

> Norme : socle v1 §S8 (revues trimestrielles = base du PV ; formation/DUERP/coffre).
> Revues : `docs/revue-modele-eco-p10-10.md` (point mort, BFR, KPIs, journal).
> Acteur : expert-comptable (consulté, seuils — RACI 00 §00.8).

## 1. Calendrier annuel

| Échéance | Action |
|---|---|
| Clôture exercice | arrêter les comptes (date fixée aux statuts) |
| <6 mois après clôture | AG d'approbation + dépôt des comptes (greffe) |
| Trimestriel (le 10) | revue §S8 : CA, marge/séjour, occupation, RevPAR, NPS, churn, CAC vs LTV |
| Annuel | revue tenir / améliorer / vendre, avec comptable (§S8) |

## 2. Dossier AG (base = 4 revues trimestrielles)

- [ ] Les 4 revues P10-10 de l'exercice (tableaux 1 page, 12 mois glissants).
- [ ] Comptes annuels (expert-comptable) : bilan, compte de résultat, annexe.
- [ ] Rapport de gestion : activité, point mort constaté, BFR, effectif
      (DUERP si salarié), formation continue, coffre successoral testé.
- [ ] Résolutions : approbation comptes, affectation résultat, quitus,
      renouvellements éventuels, point marque INPI (P10-11).

## 3. Après l'AG

- [ ] PV signé + archivage (registre décisions, avec les 4 revues en annexe).
- [ ] Dépôt des comptes au greffe <6 mois après clôture (via expert-comptable).
- [ ] Mise à jour `docs/registres/etat-reel.md` (exercice clos, chiffres clés).
- [ ] Plan année N+1 : objectifs lots/CA, recrutement (2e personne / 1er salarié),
      passage P2→P3 si seuils §S4 atteints.
